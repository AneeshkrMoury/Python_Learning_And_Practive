Welcome to my **Python Learning & Practice** repository.

This repository documents my journey of revising and strengthening Python programming, starting from the fundamentals and gradually moving toward more advanced concepts, problem-solving, Object-Oriented Programming, and practical projects.

## 🧠 Learning Approach

My approach to learning Python is based heavily on **practice rather than passive learning**.

For each topic, I try to:

1. Understand the basic concept.
2. Write a small example.
3. Solve practice problems.
4. Make mistakes.
5. Debug the code.
6. Understand why the mistake happened.
7. Rewrite the solution when necessary.
8. Apply the concept in a small program.

This means some code in the repository may not be the shortest or most advanced possible solution.

That is okay.

The purpose of this repository is to show **progress and understanding**, not to pretend that every solution was perfect on the first attempt.
